# Contributing

Contributions are very welcome to Comment Box Generator. Before adding code, make sure it follows these guidelines:

- Respect `.prettierrc`. Preferrably use an editor with an extension for it, so it formats according to the file on save.
- AI: AI usage is acceptable so long as the code is good.

Feel free to make a fork and host it youself, this project is public domain under the Unlicense so you can do whatever you want with it.
